# Settings conventions

- Use the existing settings cards, rows, and controls. New controls must match their spacing, colors, typography, and restrained appearance. Use established UI patterns.
- Name categories with short nouns. Use sentence case for row headings.
- Give each setting an intuitive title that works without a description. Add a description only for essential context the title cannot convey. Use the shortest wording possible, preferably one line. Never add walls of text.
- Keep settings uncluttered and frictionless. Remove redundant labels, decoration, and options that need lengthy explanations.
- Use action colors and icons consistently. Keep profile details and sharing controls minimal and visually aligned with the existing settings.
- Show status, addresses, and errors beside the setting they belong to.
- Hide desktop-only categories outside the desktop app. Enforce host-only actions on the server too.
